Atividade: Evoluindo a API do Karaokê

Este projeto foi desenvolvido a partir da base de código disponibilizada no repositório do professor. A implementação foi realizada seguindo o passo a passo e as orientações apresentadas no enunciado da atividade, com algumas alterações e adaptações feitas ao longo do desenvolvimento para atender aos requisitos propostos.
Durante a atividade, foram trabalhados conceitos como DAO, múltiplas músicas, rotas da API, testes HTTP e o player de karaokê no navegador. Além disso, foram feitas alterações na estrutura original do projeto para integrar esses novos recursos.
